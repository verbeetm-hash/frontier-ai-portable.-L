# Maximum Assurance Portable - transfer and release contract
The mandatory bootstrap is in v14-6/maximum-assurance-gate.js and is called before model load and before each inference. Its pinned SHA-256 refers to v14-6/maximum-assurance-protocol.txt. The protocol is injected as system context into the local model. This does not make the model reliably obey every instruction and does not activate rules in ordinary ChatGPT chats.
Transfer: a recipient needs the PWA assets on a trusted HTTPS origin and a local compatible GGUF model. No access to the original owner's Library, Drive, GitHub account or ChatGPT account is required for the protocol. The app is not a ChatGPT connector.
Release gates: (1) byte-level protocol SHA-256 matches the pinned digest; (2) missing or tampered protocol blocks loading and inference; (3) the service worker caches both protocol and gate for offline operation; (4) fresh-install online browser test; (5) offline restart and actual GGUF inference; (6) recipient-device transfer test; (7) verify no behavioral regression against V14 and V14.6.
Known limitation: SHA-256 pin inside same-origin JavaScript detects accidental or isolated tampering, not a malicious origin capable of replacing both script and protocol. Browser cache may be evicted. Service-worker update races require real browser testing. Prompt-based assurance cannot replace independent verification of model answers.
Do not merge shadow to main or claim transfer PASS until actual independent browser and recipient-device evidence. No GitHub Actions or paid compute needed for these checks.
## Strict public/private separation (mandatory)
- Public Frontier Portable is a standalone software distribution. Personal Meta Veld is a separate private environment; never bundle or synchronize its files, research, conversations, memories, task definitions, logs, Drive snapshots, credentials, API tokens, or owner-specific paths.
- Only generic, independently reviewed, privacy-sanitized portable source code, public technical documentation and bundled protocol assets may be published.
- No runtime connector, auto-import, account inheritance, cloud sync, telemetry or access to the original owner's Google Drive, ChatGPT Library, Gmail, GitHub private repositories, or scheduled tasks is authorized by this distribution.
- Any future public release must pass a secret/PII scan and inspect all changed files, build assets and service-worker cache lists. A text policy is not a technical access control; test actual network requests and permissions before asserting privacy PASS.
- Drive holds only a separate coordination/recovery snapshot. It is not a portable runtime dependency and must not be included in public release artifacts.
- When evidence is missing, report PRIVACY HOLD rather than claiming isolation is independently verified.
